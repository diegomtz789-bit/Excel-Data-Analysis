# Bike Sales Dashboard

## Overview

An interactive Microsoft Excel dashboard designed to analyze bike purchasing behavior across customer demographics and commute characteristics.

The dashboard uses interactive slicers to allow users to explore different customer segments and identify patterns in bike purchasing behavior.

## Dashboard Preview

Bike Dashboard Image.PNG

## Dashboard Features

### Average Income Per Purchase

Compares average customer income based on:

- Gender
- Bike purchase status

### Customer Age Brackets

Analyzes bike purchasing behavior across:

- Adolescents
- Middle Age
- Old

### Customer Commute

Compares bike purchasing behavior across different commute distances:

- 0–1 Miles
- 1–2 Miles
- 2–5 Miles
- 5–10 Miles
- More than 10 Miles

## Interactive Filters

The dashboard allows users to dynamically filter the analysis using slicers for:

- Marital Status
- Region
- Education
- Number of Cars

## Tools & Skills Demonstrated

- Microsoft Excel
- PivotTables
- PivotCharts
- Interactive Slicers
- Data Filtering
- Data Analysis
- Data Visualization
- Dashboard Design

## Project Purpose

The purpose of this project is to demonstrate how Microsoft Excel can be used to transform customer data into an interactive analytical dashboard.

The dashboard provides a visual way to explore relationships between customer demographics, income, commute distance, vehicle ownership, and bike purchasing behavior.

## Project Files

- [Bike Sales Dashboard](Bike_Sales_Dashboard.xlsx) — Excel workbook containing the interactive dashboard and supporting analysis.

## Key Takeaways

The dashboard enables users to explore customer purchasing patterns by applying different demographic and geographic filters. This allows the underlying dataset to be analyzed from multiple perspectives rather than relying on a single static report.
